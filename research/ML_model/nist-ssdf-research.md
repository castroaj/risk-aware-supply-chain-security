## 1. Introduction

The NIST Secure Software Development Framework (SSDF), Special Publication 800-218 (2022), provides a structured set of practices to reduce vulnerabilities in software and mitigate the impact of exploited weaknesses (NIST, 2022).

The SSDF emphasizes:
- Risk-based security decision-making  
- Secure build and release processes  
- Software supply chain transparency  
- Traceability and documentation  
- Continuous improvement  

This research analyzes how our Decision Tree–based machine learning (ML) deployment gate within a CI/CD pipeline will align with and operationalize SSDF guidance.
